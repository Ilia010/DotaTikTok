# DotaTikTok

Оверлей с TikTok поверх Dota 2. Безрамочное окно висит поверх игры, вход в аккаунт сохраняется между запусками, управление — с клавиатуры, не выходя из матча.

## Возможности

- Окно всегда поверх остальных (в режиме Borderless Windowed).
- Глобальная горячая клавиша `Ctrl+Shift+T` — показать/скрыть из игры.
- Перетаскивание за шапку и изменение размера за правый нижний угол.
- Выключение звука и перезагрузка страницы из шапки.
- Иконка в трее с меню: показать/скрыть, перезагрузить, сбросить вход, выход.
- Позиция, размер и состояние звука сохраняются между запусками.
- Один экземпляр приложения (защита от двойной регистрации горячей клавиши).

## Требования

- Windows 10/11 (x64).
- [.NET 10 SDK](https://dotnet.microsoft.com/download) — для сборки.
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) — обычно уже установлен вместе с Windows/Edge.

## Сборка и запуск

```powershell
dotnet build -c Release
.\bin\Release\net10.0-windows\DotaTikTok.exe
```

Для запуска без установленного SDK можно собрать self-contained версию:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true
```

## Управление

| Действие | Как |
|---|---|
| Показать / скрыть окно | `Ctrl+Shift+T` (работает из игры) |
| Скрыть | `Esc` или ✕ в шапке |
| Перетащить окно | тянуть за шапку |
| Изменить размер | угол в правом нижнем углу |
| Выключить звук | 🔇 в шапке |
| Перезагрузить | ⟳ в шапке |
| Меню (сброс входа, выход) | правый клик по иконке в трее |

## Важно

- **Dota 2 должна быть в режиме «Borderless Windowed»** (Настройки → Видео → Display Mode). В эксклюзивном полноэкранном режиме никакое стороннее окно поверх игры не отображается — это ограничение Windows, а не приложения.
- Приложение подменяет User-Agent на десктопный Chrome: TikTok отдаёт WAF-заглушку на стандартный UA WebView2/Edge.
- Вход выполняется один раз: cookies лежат в `%APPDATA%\DotaTikTok\webview`, поэтому сессия живёт между запусками. «Сбросить вход» в трее — если надо войти в другой аккаунт.
- Настройки (размер, позиция, звук) — `%APPDATA%\DotaTikTok\settings.json`.

## Устройство

- `Program.cs` — точка входа, защита от второго экземпляра (иначе горячая клавиша регистрируется дважды и не работает).
- `OverlayForm.cs` — всё окно: безрамочная форма `TopMost`, шапка с кнопками, WebView2 на весь остаток, `RegisterHotKey` через `WndProc`, иконка в трее, сохранение настроек.
- `DotaTikTok.csproj` — WinForms-проект под `net10.0-windows` с пакетом `Microsoft.Web.WebView2`.
